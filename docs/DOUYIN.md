# 抖音支持

BDL 可以把单条抖音作品保存到本机：标题、作者、封面、发布日期和时长取自作品信息，视频保存为 MP4/MKV，或按预设转成 MP3。

## 支持的输入

| 输入 | 示例 |
| --- | --- |
| 作品页 | `https://www.douyin.com/video/7709208428677229898` |
| 图文页 | `https://www.douyin.com/note/7680883233307342947`（仅识别，见下文限制） |
| 分享页 | `https://www.iesdouyin.com/share/video/7709208428677229898/` |
| 分享短链 | `https://v.douyin.com/G8Oggg_IXMA/` |
| 分享口令 | 复制整段「7.32 复制打开抖音…」文本，BDL 会提取其中的链接 |

合集、搜索结果、用户主页和直播间不是单条作品，BDL 暂不支持。粘贴这类链接会得到“无法识别这个输入”的提示。

## 解析方式

抖音网页接口带有运行时签名（`a_bogus` / `x-tt-argus`），匿名请求无法直接取得播放地址；分享页也不再内嵌作品数据。因此 BDL 通过一个解析服务换取播放地址：

- 默认使用公开解析服务 `https://api.xingzhige.com/API/douyin/`。
- 通过环境变量 `BDL_DOUYIN_API` 可以换成自建服务，启动 BDL 前设置即可。
- BDL 会把作品的标准链接（`https://www.douyin.com/video/<作品 ID>`）作为 `url` 参数发出，并要求返回同样的 `/API/douyin/` JSON 结构。
- 返回结果的作品 ID 必须与所选作品一致，否则 BDL 报错而不是下载错误的内容。

这意味着解析会把作品链接发给该服务；如果你不希望这样，请不要解析抖音链接，或把 `BDL_DOUYIN_API` 指向你自己的服务。

播放地址是带时效的抖音 CDN 链接。解析后请尽快下载；过期后重新解析再创建任务。

## 下载与输出

- 抖音视频是“音视频合一”的单文件，BDL 只下载一次：选择「音频+视频」时直接封装，不会重复下载同一个文件。
- 选择「仅音频（MP3）」时，BDL 下载该文件后用 FFmpeg 提取音轨转成 MP3（桌面端仍需要 FFmpeg）。
- 封面、NFO 等归档素材与其他来源一致，可在预设中勾选。
- 抖音作品没有分 P、弹幕和字幕，相关开关会显示“来源没有提供…”并跳过。

## 已知限制

- **图文（图集）作品**暂不支持：BDL 的成品模型是音视频文件。解析时会给出明确提示。
- **用户主页 / 合集**：需要签名分页接口，暂未实现。
- 解析依赖第三方服务时的可用性；服务限速或变更时，请稍后重试或更换 `BDL_DOUYIN_API`。
